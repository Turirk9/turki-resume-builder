## المشكلة

أدوات بناء السير الذاتية مبنية للإنجليزية: تكسر اتجاه النص العربي، وتخلط الأرقام بالحروف،
وترتّب الحقول بمنطق القراءة من اليسار. وأغلبها يطلب حسابًا، ويرفع بياناتك الشخصية إلى خادمه،
ثم يضع علامته المائية على ملفك أو يطلب اشتراكًا لتنزيله.

## الحل

تطبيق صفحة واحدة يعمل بالكامل داخل المتصفح، بثلاث واجهات: صفحة تعريفية، معرض قوالب، ومنشئ السيرة.

### القوالب
**١٤ قالبًا مختلفًا فعلًا** — لا ألوانًا متبدّلة: كلاسيكي · عصري · بسيط · تنفيذي · خط زمني · إبداعي ·
أكاديمي · تقني · متوافق ATS · طالب · شركات · راقٍ · مضغوط · جريء.
لكل قالب تخطيطه وترتيب أقسامه وتايبوغرافيته — قالب الطالب يقدّم التعليم والمشاريع،
والتقني يقدّم المهارات، والأكاديمي يقدّم التعليم والدورات.

معرض القوالب فيه **بحث** و**تسعة تصنيفات** ومرشّح **متوافق ATS**،
وكل معاينة فيه هي القالب الحقيقي مرسومًا ببيانات نموذجية — لا صورة تقريبية.

## قرارات تقنية

**١. أربعة محرّكات تخطيط تخدم أربعة عشر قالبًا.**
بدل أربع عشرة دالة رسم، هناك `stack` و`sidebar` و`centered` و`columns`،
وكل قالب يعلن أيها يستخدم وبأي ترتيب أقسام، ثم يُلبسه CSS هويته.
إضافة قالب خامس عشر = سطر في `TEMPLATES` وكتلة CSS.

**٢. الرابط هو قاعدة البيانات.**
JSON ← ضغط `deflate` عبر `CompressionStream` ← `base64url` ← بعد `#` في العنوان.
مشاركة كاملة بلا بنية تحتية، وأول حرف في الرمز يحدد النسخة فتبقى الروابط القديمة صالحة.

**٣. تحليل السيرة يفحص المحتوى لا الحقول.**
لا يسأل «هل عبّأت الخانة؟» بل «هل النقطة مدعومة برقم؟ هل تبدأ بفعل قوي؟ هل النبذة بطول مناسب؟»
وكل خصم يقابله اقتراح قابل للتنفيذ.

**٤. معاينات الورق داخل حاوية قصّ بتموضع فيزيائي.**
`position:absolute; top:0; left:0` و`transform-origin: 0 0` وقيمة مقاس محسوبة في JS —
لا تتأثر باتجاه الصفحة ولا بانكماش flex ولا بترتيب تحميل الأنماط،
ويعيد `ResizeObserver` ضبطها عند أي تغيّر.

**٥. لا نعيد رسم النموذج مع كل ضغطة مفتاح.**
الكتابة تحدّث المعاينة فقط؛ وإعادة بناء النموذج تحدث عند التغييرات البنيوية فقط،
وإلا لفقد المستخدم مؤشر الكتابة مع كل حرف.

**٦. تصدير PDF عبر الطباعة لا عبر مكتبة.**
`window.print()` مع ورقة `@media print` تعطي نصًا حقيقيًا قابلًا للبحث وبحجم صغير،
بينما مكتبات HTML→PDF تنتج صورة ثقيلة وتكسر العربية غالبًا.

**٧. الحركة تحسين اختياري لا شرط للعرض.**
لا يُخفى أي محتوى إلا بعد أن يعلن JS قدرته على إظهاره، مع شبكة أمان زمنية،
واحترام كامل لـ`prefers-reduced-motion`.

## أخطاء تعلّمت منها

| العَرَض | السبب الجذري |
|---|---|
| PDF يخرج صفحة بيضاء | `@media (max-width)` يقيس **الورقة** لا الشاشة عند الطباعة، فتُفعَّل قواعد الجوال وتُخفي المعاينة |
| القالب يظهر مشوّهًا في المعاينة | ورقة A4 عنصر flex، والعناصر تنكمش افتراضيًا: 794px ← 434px قبل التصغير |
| السيرة تغطّي التذييل | العناصر المُموضَعة تُرسم فوق العادية مهما كان ترتيبها في المستند |
| بطاقات البطل تتراكب | حركة تتبّع الفأرة تطبّق `rotateY` فتلغي مواضع العناصر |
